# PrepKit AI - Client

The frontend web application for [PrepKit AI](../README.md), built with **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS**.

## Features

- **Personalized Kit Builder**: Inline question editing, difficulty adjustment, pinning, and category-level regeneration.
- **Interactive Rehearsal Room**: Timed verbal AI mock interview simulator with speech recognition and instant rubric grading.
- **Spaced Repetition Flashcards**: Interactive 3D flip cards with confidence ratings and adaptive progress tracking.
- **Daily Prep Timeline**: Day-by-day arithmetic schedule with topic breakdown.
- **Printable Dossier**: One-click print / PDF export stylesheet for offline interview preparation.
- **Mobile Responsive**: Fully responsive UI with animated mobile navigation drawer.

## Getting Started

Run the development server from the repository root:

```bash
npm run dev
```

Or run the client independently:

```bash
cd client
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide Icons
- **Language**: TypeScript
